How to launch Program -
    cd <project dir>
    $ python -m http.server       # python 3
    $ python -m SimpleHTTPServer    # python 2
    Access localhost:8000 on a browser

Using the Program -
    Buttons on screen do
    - Local and global rotations
    - Switching between texture mapped, lighting and wireframe rendering of parametric objects
    
    Camera Controls -
    - W, A, S, D - Move Camera
    - Arrow keys - Pitch and Yaw

Features in Program -
    - Texture mapping on planar surface
    - Texture mapping on to parametric surface
    - Toggle parametric surface between texture, lighted and wireframe
    - 6 walls to represent environment
    - Environment mapping on basic object (Cube)
    - Environment mapping on parametric object
    - Self animation
    - Hierarchical model
    - Lighting
    - Global rotation
    - Local rotation
    - Bump mapped sphere

Bonus Tasks attempted -
    - Bump mapping

Development Environment
    OS - Linux (Ubuntu 19.10)
    Browser - Firefox 70.0
